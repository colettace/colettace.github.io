Fearless

Consultant, Data & Analytics · September 2022–present · Baltimore

At Fearless, I work on public-sector data architecture and engineering. My assignments have included:

  • Maryland FAMLI — platform architecture: compared Databricks and AWS-native lakehouse approaches and developed implementation blueprints, engineering standards, and governance practices.
  • OPM/USPS Postal Service Health Benefits — data pipelines: architected enrollment and eligibility processing in Databricks, with reconciliation, exception handling, and monitoring.
  • SEC Data Prism — structured data integration: built XML-to-relational transformations, automated schema generation, and AWS Glue and Airflow workflows using Apache Iceberg.
  • CDC — distributed analytics: migrated disease-surveillance processing from local R workflows to Databricks using SparkR and sparklyr, and contributed governance guidance.
  • USDA Farm Loan Program — legacy modernization: reconstructed COBOL/IDMS mainframe data models and prepared schema documentation and migration artifacts.
  • USGS 3DEP — geospatial discovery: built a prototype for publishing and discovering geospatial data using containerized services and STAC metadata.
  • Team development: mentoring engineers through pair programming, technical reviews, and coaching.
