Fearless · Office of Personnel Management

Making a benefits data platform understandable

Data engineering and automated documentation for OPM’s Postal Service Health Benefits platform, through my work at Fearless.

Baltimore, Maryland

At Fearless, I worked as a data engineer on the Office of Personnel Management’s Postal Service Health Benefits data platform. Our team brought the congressionally mandated platform live on schedule under significant deadline pressure.

The challenge

Enrollment and eligibility information arrived from multiple agencies and partner organizations, including gigabyte-sized text files generated by mainframe systems. The data needed to become consistent, usable inputs for downstream dashboards—and the people operating the platform needed to understand what was running.

From mainframe files to usable data

I contributed to the team’s Databricks data engineering work using Python, Pandas, PySpark, and SQL. The workflow ingested and transformed incoming data through bronze, silver, and gold layers, with Azure Data Factory moving files and input archiving preserving the source material for replay and reprocessing.

Operational dashboards used the Databricks API to represent the current state of the system. Together, the pipelines and operational visibility supported the team’s delivery of the mandated platform.

Documentation people could help maintain

One contribution I built was automated system documentation using Python and Jinja2. It combined live information from the Databricks API with human-editable spreadsheets maintained by leadership.

The generated documentation described jobs, their tasks, and the files and notebooks they ran. Engineers could supply current system metadata, while nontechnical stakeholders could update descriptions without editing code.

That connection mattered: documentation could reflect both what the system actually did and the context people needed to understand it.

The outcome

Our team delivered the platform on the required schedule. My documentation automation provided a maintainable way to combine technical system information with leadership’s knowledge.

This project captures what I value in data engineering: making the data move, making the system observable, and making its operation understandable to the people responsible for it.
